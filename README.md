\## 🎯 Objetivo do Software

O sistema tem como objetivo auxiliar no \*\*controle de estoque de produtos\*\*, permitindo o \*\*cadastro, consulta e movimentação\*\* (entrada e saída) de itens.  

Além disso, conta com \*\*controle de usuários e permissões\*\* para diferentes cargos (Administrador, Funcionário e Gestor).



\## ⚙️ Funcionalidades do Sistema

\- Tela de \*\*login\*\* com autenticação de usuários

\- \*\*Menu principal\*\* com opções de acesso conforme o cargo do usuário

\- \*\*Cadastro de usuários\*\* (administrador)

\- \*\*Cadastro de produtos\*\* com validação de validade e estoque mínimo/máximo

\- \*\*Movimentação de estoque\*\* (entrada e saída)

\- \*\*Consulta de produtos\*\* com opção de exclusão e atualização da lista

\- \*\*Listagem de movimentações\*\* realizadas

\- \*\*Recuperação de senha\*\* simulada



\## 🗄️ Banco de Dados

Banco de dados criado em \*\*MySQL\*\*, com tabelas:

\- `usuarios`

\- `produtos`

\- `movimentacao\_estoque`

\- `lotes`
